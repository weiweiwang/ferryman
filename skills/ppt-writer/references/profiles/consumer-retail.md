# consumer-retail

Use for consumer, retail, lifestyle, travel, people, places, products, classroom
sharing, family decks, and other image-led storytelling.

Hard gates:

- Set `media_required=true`.
- Use real assets, user-provided assets, generated images, or verified visual
  sources with provenance.
- Composition should be editorial: fewer words, stronger image hierarchy, clear
  captions.
- For `classroom-sharing`, target 3-8 slides, direct language, and no adult
  boardroom jargon.
- Do not reuse one generic image across the whole deck unless it is intentional
  background texture.
