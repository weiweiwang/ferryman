# appendix-heavy

Use for dense tables, source packs, disclosures, appendices, and reference
materials.

Hard gates:

- Tables need explicit header, row, unit, and source grammar.
- Small text must remain readable after render.
- Use page markers and section labels so readers can navigate.
- Do not turn every dense slide into the same boxed grid.
- If a table is too dense for a main slide, split it or move it to appendix.
